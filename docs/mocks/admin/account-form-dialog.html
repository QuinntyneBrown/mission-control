Length is the only password rule, and both bounds get field messages: "Use at least 12 characters." or "Use 128 characters or fewer." The input has no maxlength, so a longer pasted password is reported instead of silently cut. Valid input is kept.

Account emails are unique after trimming and case folding, so the API answers 409 and no account is created. Lead contacts don't count: a lead may share an account's email.

Save shows progress and ignores repeat clicks, so only one account can be created.
