Administrator-only; signed-in collaborators who open this URL get the access-denied page. Accounts and lead contacts are separate records: changing one never changes the other, and this page doesn't look up lead contacts.

No account can be deleted: there is no delete endpoint. The designated administrator can't be deactivated, demoted, renamed, or have its email changed; the API answers 409 and records a Rejected audit event if anyone tries. Deactivate stays visible but disabled, and the reason is written out rather than hidden in a tooltip. Edit opens the account dialog with every field locked. Replacing the password is allowed.

Deactivation keeps the account, its assignments, and its audit history. Jordan's existing token stops working on the next request. Reactivate restores sign-in with the existing password.

Shown for an unknown account ID. Accounts are never deleted, so this usually means a mistyped or outdated link. An account dialog whose read or save answers 404 closes onto this page too; no reference ID or Try again, because nothing failed.

Screen readers hear "Loading account". The skeleton keeps the header and details layout so nothing jumps when data arrives.

The read failed, so no account details or actions are shown, and nothing is shown as missing. Focus moves to the heading and the alert is announced. Try again repeats the read.
