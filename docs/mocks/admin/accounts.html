Administration · Accounts All mocks

Administrator-only. A collaborator never sees the Accounts link, and a signed-in collaborator who opens this URL directly sees the access-denied page. Quinntyne Brown is the designated administrator: there is no Deactivate action for that account. Below 768px each row becomes a labelled card. After an account dialog saves, the list rereads and a toast names the account ("Account added", "Changes saved", "Account deactivated", "Account reactivated", or "Password replaced"); a dialog that finds its account missing closes, and the list rereads with the toast "Account not found". With more than 25 accounts the list reads "Showing 1–25 of N accounts" and shows the lead directory's pager; changing page reads at once.

A skeleton holds the table's shape while accounts load, so the page never looks empty. Screen readers hear "Loading accounts".

The request failed with a 500, shown here with its reference ID, which matches the server's diagnostic record. A request that got no response reads "Check your connection and try again." without a reference ID, because no response carried one. Try again repeats the request in both cases. A refused page request (400) shows the API's message here instead, without Try again or a reference ID, because repeating it would be refused again. A 403 means you're no longer an administrator: the access-denied page replaces Accounts.
