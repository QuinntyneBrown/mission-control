On success the dialog closes, the board re-reads the two affected columns, focus returns to the moved card's Move button at its new place, and a toast confirms "Moved to In Progress — "Mentors can see team needs" is position 2 of 3." Below 576px the column selector first switches to the destination column; if the new position is beyond that column's loaded cards, focus goes to its Load more instead. If the board changed since it loaded, or the API refused the move as invalid (400), the dialog closes, the board shows its page alert with Reload board (no Retry), and focus moves to Reload board. If access changed (an unexpected 403), the dialog closes, focus returns to the card's Move button, and the "Your access changed" toast appears without Retry. If the project's delivery mode changed, the dialog closes and the Board tab shows the board for the new mode, with focus on its heading. If the story was deleted (404), the dialog closes and the board reloads without it, with focus on the board region; if the whole project was deleted, the board shows "Project not found" with Back to projects.

A server error (500) or a busy workspace (503): nothing moved and the card keeps its last saved place. The alert is announced and focus stays on Move story. The choices are kept, so Move story retries the same move. A refused move (400) never shows here, because resending it would be refused again: the dialog closes and the board explains the refusal with Reload board. If no response arrives at all, the move may have gone through, so this alert is not shown and nothing claims the story didn't move: the dialog closes and the board re-reads the affected columns to show where the story really is before any other move; focus then returns to the card's Move button.
