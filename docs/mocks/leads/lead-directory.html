Leads · Directory All mocks

25 leads per page, ordered by last name, then first name. Wide screens show a table; below 768px each row becomes a labelled card. Edit and delete are administrator-only.

Collaborators can read every contact. Add, edit, and delete are absent, and the notice explains why. Direct API calls are still denied.

Search is a trimmed, case-insensitive substring of first, last, or full name, email, or phone. It combines with the category using AND across all pages. Changing either resets to page 1, and screen readers hear "4 leads found". Chip counts are totals for each category across all leads, so they don't change with search or filter.

Home's "Event 0" card opens this view. Screen readers hear "No Event leads found". Clear filter restores the full directory.

After a confirmed delete the directory reloads without the lead, the total drops to 36, and a toast confirms what changed. Focus returns to the page heading.

A skeleton holds the layout while leads load, so the page never looks empty. Category counts appear only with the loaded result. Screen readers hear "Loading leads".
