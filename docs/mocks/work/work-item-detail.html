The breadcrumb gives the full parent path; each ancestor opens its own detail view. Below 576px the middle levels fold into the "…" menu. Updating the status to Done while tasks are unfinished asks for confirmation first. Task status changes are announced, for example "Add team capacity limits marked Done".

Initiatives are the top level. They have no parent and no "Move to another parent" action. Initiatives and epics are not estimated and don't join sprints.

Each epic belongs to one initiative in the same project. Its stories keep their own sprint membership.

Tasks follow their story's sprint and have no estimate of their own.

Optional values that are empty are labelled, never left blank.

The title was saved as typed. It shows as plain text and never runs as code. Inactive people keep existing assignments but don't appear in assignee pickers.

Collaborators can edit, change status, and move work. Delete is disabled with its reason.

The ID in the link doesn't exist or the item was deleted. Navigation offers the project and the project list.

A skeleton holds the layout while the item loads. Screen readers hear "Loading work item".
